
# Smart Crop Recommendation System

A machine learning web application that recommends a suitable crop based on soil nutrients and weather conditions.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Random Forest Classifier
- Flask
- HTML and CSS

## Features
- Takes soil and weather inputs
- Predicts a suitable crop using a trained ML model
- Provides a simple, responsive web interface

## How to Run
1. Install the required libraries:
   `pip install -r requirements.txt`
2. Run the application:
   `python app.py`
3. Open `http://127.0.0.1:5000` in your browser.
